SEATSCAPE v44 - C5 initial view + front wall visibility

Changes from v43:
1. Initial camera mode: seated first-person at C5, facing the screen.
2. The front/screen wall is no longer automatically hidden when the orbit camera moves in front of it.
3. Previous v43 side-wall visibility fix retained.

Unchanged: seat coordinates/count (34), levels, rails, stairs, speakers and all auditorium geometry.

Note: In full-orbit mode the front wall can naturally obscure the seats when viewing from outside the screen wall. Use the existing Overview/Top buttons to change viewpoint.
